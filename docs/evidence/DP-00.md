## Contrato da demonstração

- Dados exclusivamente sintéticos e marcados como sem valor fiscal; sem documentos reais de visitantes.
- Contas individuais por convite (`INVITE_CODE`, compartilhado fora do repositório e do bundle).
- Uma empresa/estoque por sessão de exemplo (DP-02), isolados por visitante.
- Gemini real; `GEMINI_QUOTA_ENFORCEMENT_ENABLED=false` (medição preservada, kill switch `GEMINI_ENABLED` independente). Rate limits HTTP, autenticação, validação, transações e idempotência continuam ativos.
- **Modalidade planejada: web (DP-03), mesma origem servida pelo backend.** É a sequência padrão do roadmap; não houve decisão registrada de retirar DP-03. Consequência: CORS pode permanecer vazio (mesma origem); um cliente sem `Origin` continua autenticado por JWT. Se a modalidade mudar para API, DP-05 usa o roteiro HTTP e este item deve ser atualizado antes de DP-04.
- Disponibilidade depende do provedor; sem promessa de capacidade.

## Lista de gaps

**Bloqueadores do primeiro piloto**
1. Correspondência exata por código sem fornecedor/unidade → DP-01.
2. Auditoria de dependências de produção não reexecutada → DP-01.
3. Chaves de nota e CNPJ únicos globalmente impedem repetição sem Python/SQL → DP-02.
4. Ausência de jornada web (se a modalidade web for mantida) → DP-03.
5. SHA/URL/migrations/configuração hospedados não verificados; release com a base atual não publicada → DP-04 (inventário B01/B03/B04 precisa ser fechado antes do aceite).
6. Identificador público de versão para provar a release publicada (não existe) → DP-04.
7. Smoke, rollback e reconstrução não ensaiados; testes empíricos de proxy, CORS e cold start pendentes → DP-04.
8. Fluxo real hospedado com Gemini → DP-05.

**Melhorias opcionais:** observação de SIGTERM real no Render; atestado do método de geração do `JWT_SECRET` (pode virar bloqueador se não puder ser atestado — rotação invalida sessões).

**Requisitos comerciais futuros:** backup/restore com RPO/RTO, recuperação de senha por e-mail, orçamento por usuário, provedor pago, SLA, batching/calibração de similaridade, suporte a documentos reais.
